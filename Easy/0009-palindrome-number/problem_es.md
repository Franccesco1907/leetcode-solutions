# 9. Palindrome Number

[Enlace de LeetCode](https://leetcode.com/problems/palindrome-number/)

## Descripción

Dado un número entero "x", devuelve "verdadero" si "x" es un **palíndromo** y "falso" en caso contrario.

 

**Ejemplo 1:**

```texto

**Entrada:** x = 121
**Salida:** verdadero
**Explicación:** 121 se lee como 121 de izquierda a derecha y de derecha a izquierda.

```

**Ejemplo 2:**

```texto

**Entrada:** x = -121
**Salida:** falso
**Explicación:** De izquierda a derecha, se lee -121. De derecha a izquierda, se convierte en 121-. Por tanto no es un palíndromo.

```

**Ejemplo 3:**

```texto

**Entrada:** x = 10
**Salida:** falso
**Explicación:** Lee 01 de derecha a izquierda. Por tanto no es un palíndromo.

```

 

**Restricciones:**


* `-231 <= x <= 231 - 1`

 

**Seguimiento:** ¿Podrías resolverlo sin convertir el número entero en una cadena?
