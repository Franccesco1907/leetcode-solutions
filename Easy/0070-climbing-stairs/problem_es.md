# 70. Climbing Stairs

[Enlace de LeetCode](https://leetcode.com/problems/climbing-stairs/)

## Descripción

Estás subiendo una escalera. Se necesitan "n" pasos para llegar a la cima.

Cada vez puedes subir "1" o "2" escalones. ¿De cuántas maneras distintas puedes subir a la cima?

 

**Ejemplo 1:**

```texto

**Entrada:** n = 2
**Salida:** 2
**Explicación:** Hay dos formas de subir a la cima.
1. 1 paso + 1 paso
2. 2 pasos

```

**Ejemplo 2:**

```texto

**Entrada:** n = 3
**Salida:** 3
**Explicación:** Hay tres formas de subir a la cima.
1. 1 paso + 1 paso + 1 paso
2. 1 paso + 2 pasos
3. 2 pasos + 1 paso

```

 

**Restricciones:**


* `1 <= n <= 45`
