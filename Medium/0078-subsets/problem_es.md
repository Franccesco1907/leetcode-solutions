# 78. Subsets

[Enlace de LeetCode](https://leetcode.com/problems/subsets/)

## Descripción

Dada una matriz entera `nums` de elementos **únicos**, devuelve todos los subconjuntos posibles (el conjunto potencia).

El conjunto de soluciones **no debe** contener subconjuntos duplicados. Devuelva la solución en **cualquier orden**.

 

**Ejemplo 1:**

```texto

**Entrada:** números = [1,2,3]
**Salida:** [[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]

```

**Ejemplo 2:**

```texto

**Entrada:** números = [0]
**Salida:** [[],[0]]

```

 

**Restricciones:**


* `1 <= números.longitud <= 10`

* `-10 <= números[i] <= 10`

* Todos los números de `nums` son **únicos**.
